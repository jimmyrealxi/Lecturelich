# กติกาดีไซน์ StudyQuest — ธีม "สมุดเทอร์มินัล"

> ค่าสีและฟอนต์ทั้งหมดอยู่ที่ `lib/theme.ts` ที่เดียว ห้ามเขียนรหัสสีลงในหน้าโดยตรง · ตัวอย่างหน้าตา `docs/mockups/retro-theme.html` (v3 อนุมัติ 7 พ.ย. 2569)

## หน้าใช้งาน (สมุดบันทึกบนเทอร์มินัล กราไฟต์อุ่น ไม่ใช่นีออน)
| token | สี | ใช้กับ |
|---|---|---|
| `ink` | `#121513` | พื้นหลังหน้า |
| `deck` | `#181C19` | แผง/การ์ด แถบแท็บ · ตัวหนังสือบนพื้น `go`/`warn` |
| `rule` / `rule2` | `#2B322D` / `#3A433C` | เส้นแบ่ง / ขอบปุ่ม ช่องว่างของแถบ |
| `paper` | `#E2E7DF` | ตัวหนังสือหลัก |
| `muted` / `faint` | `#A2ADA4` / `#8A968D` | ข้อความรอง / ข้อความประกอบ ป้ายแท็บที่ไม่ได้เลือก |
| `go` | `#86D99B` | สีหลัก: กำลังเรียน ปุ่มที่เลือก ขีดแท็บ |
| `warn` | `#F0B35A` | สีเน้น: ค้าง ใกล้ส่ง LV |
| `danger` / `dangerBg` | `#F07167` / `#2A1715` | ขาดเรียน เลยกำหนด |

- มุมเหลี่ยมทั้งแอป (`radius` = 0) · ไม่ใช้เงา ใช้เส้น 1px
- หน้าวันนี้: ตัวเด่นตัวเดียว (กำลังเรียน/คาบถัดไป/งานใกล้สุด) ที่เหลือเป็น "บรรทัดบันทึก" มีเวลา ไม่ใช่การ์ดซ้อน
- เส้นสแกนมีจุดเดียวในแอป: ตัวเลขนาฬิกาหน้าวันนี้
- แถบแท็บ: แผงทึบติดขอบล่าง ขีดสีเหนือแท็บที่เลือก ไอคอนเส้นเหลี่ยม (`components/TabIcon.tsx`) ป้ายเลขงานค้าง

## หน้าเกม ("อีกโลก" ดาร์กแฟนตาซี ผิวหิน ทองหม่น)
- พื้น `cave` `#0F0D0C` · ช่องแถบ `gameDeep` · กล่อง `gamePanel` · เส้น `seam` `#3B3027`
- ตัวหนังสือ `bone` / รอง `ash` · จุดเด่น `gold` `#C9A25B` · เลือดบอส `blood` · กรอบบอส `bossLine`
- **สีความหายาก** (`rarity`): ขาว ปกติ · ฟ้า magic · เหลือง rare · ส้ม unique
- ภาพพิกเซลใช้ `image-rendering: pixelated` (SVG ใช้ `shape-rendering="crispEdges"`)
- ยืมแค่บรรยากาศ ห้ามใช้ภาพ ไอคอน ชื่อ ฟอนต์ หรือโลโก้จาก Fallout / Path of Exile

## ฟอนต์
| token | ฟอนต์ | ใช้กับ |
|---|---|---|
| `heading` / `headingBold` | Chakra Petch 600/700 | หัวข้อ ปุ่ม แท็บ |
| `body` / `bodyMedium` / `bodyBold` | IBM Plex Sans Thai 400/500/600 | เนื้อหา |
| `num` | VT323 | **ตัวเลข/เวลาเท่านั้น** ห้ามใช้กับคำไทย |
| `pixel` | Silkscreen | คำอังกฤษสั้น เช่น LV XP HP |

- ขนาดตัวหนังสือเนื้อหาไม่ต่ำกว่า 14 · ตัวเล็กสุด (ป้ายแท็บ ข้อความประกอบ) 12

## การใช้งาน
- ปุ่ม/จุดกดสูงอย่างน้อย 44px (`minTouch`) · คอนทราสต์ ≥ 4.5:1 · ใช้ได้ตั้งแต่จอ 360px
- แท็บล่าง 5 แท็บ: วันนี้ · วิชา · งาน · เกม · ตั้งค่า
- โหลด = skeleton ไม่ใช้วงกลมหมุน
- แอนิเมชันใช้ `transform` / `opacity` เท่านั้น · เคารพ reduce motion
- การกดที่ย้อนได้ (ติ๊กส่งงาน) = แถบ "ยกเลิก" 3 วินาที
