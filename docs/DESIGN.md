> ค่าสีและฟอนต์ทั้งหมดอยู่ที่ `lib/theme.ts` ที่เดียว ห้ามเขียนรหัสสีลงในหน้าโดยตรง · โครงหน้า `docs/mockups/retro-theme.html` (v3) · สี `docs/mockups/retro-theme-blue.html` **แบบ B** (อนุมัติ 7 พ.ย. 2569)

## หน้าใช้งาน (สมุดเทอร์มินัล โทนยูนิฟอร์ม: พื้นเทาอ่อน + แผงน้ำเงิน + ขีดเหลือง)
| token | สี | ใช้กับ |
|---|---|---|
| `ink` | `#E6E9EE` | พื้นหลังหน้า |
| `deck` | `#F3F5F8` | การ์ด ช่องกรอก แผ่นล่าง |
| `rule` / `rule2` | `#C7CDD6` / `#B5BDC9` | เส้นแบ่งบาง / ขอบปุ่ม |
| `paper` | `#14213A` | ตัวหนังสือหลัก · ตัวหนังสือบนพื้นเหลือง |
| `muted` / `faint` | `#4A5873` / `#5C6982` | ข้อความรอง / ประกอบ |
| `go` | `#F2C230` | เหลือง: ปุ่มที่เลือก ขีดใต้หัว ขีดแท็บ · **เป็นพื้นหรือบนน้ำเงินเท่านั้น** |
| `warn` | `#A84B0C` | ส้มเข้ม: ค้าง ใกล้ส่ง |
| `danger` / `dangerBg` | `#B3261E` / `#FBE9E7` | ขาดเรียน เลยกำหนด |
| `navy` / `navyDeep` / `navyRule` | `#1E3D74` / `#173162` / `#34558F` | แผงเด่น แถบแท็บ / หัวหน้า / เส้นบนน้ำเงิน |
| `onNavy` / `onNavyMuted` / `onNavyFaint` | `#F4F6FA` / `#C2CDE0` / `#A9B8D2` | ตัวหนังสือบนน้ำเงิน |

- **ห้ามตัวหนังสือเหลืองบนพื้นอ่อน** · หัวหน้า = `navyDeep` + ขีดเหลือง 3px ด้านล่าง ชื่อหน้าสีเหลือง
- มุมเหลี่ยมทั้งแอป (`radius` = 0) · ไม่ใช้เงา ใช้เส้น 1px
- หน้าวันนี้: ตัวเด่นตัวเดียวบนแผงน้ำเงิน (กำลังเรียน/คาบถัดไป/งานใกล้สุด) ที่เหลือเป็น "บรรทัดบันทึก" มีเวลา
- เส้นสแกนมีจุดเดียวในแอป: ตัวเลขนาฬิกาหน้าวันนี้
- แถบแท็บ: แผงน้ำเงินทึบ ขีดเหลืองเหนือแท็บที่เลือก ไอคอนเส้นเหลี่ยม (`components/TabIcon.tsx`) ป้ายเลขงานค้าง

## หน้าเกม ("อีกโลก" ดาร์กแฟนตาซี ผิวหิน ทองหม่น)
- พื้น `cave` `#0F0D0C` · ช่องแถบ `gameDeep` · กล่อง `gamePanel` · เส้น `seam` `#3B3027`
- ตัวหนังสือ `bone` / รอง `ash` · จุดเด่น `gold` `#C9A25B` · เลือดบอส `blood` · กรอบบอส `bossLine`
- **สีความหายาก** (`rarity`): ขาว ปกติ · ฟ้า magic · เหลือง rare · ส้ม unique
- ภาพพิกเซลใช้ `image-rendering: pixelated` (SVG ใช้ `shape-rendering="crispEdges"`)
- ยืมแค่บรรยากาศ ห้ามใช้ภาพ ไอคอน ชื่อ ฟอนต์ หรือโลโก้จาก Fallout / Path of Exile

## ฟอนต์
| token | ฟอนต์ | ใช้กับ |
|---|---|---|
| `heading` / `headingBold` | Chakra Petch 600/700 | หัวข้อ ปุ่ม แท็บ |
| `body` / `bodyMedium` / `bodyBold` | IBM Plex Sans Thai 400/500/600 | เนื้อหา |
| `num` | VT323 | **ตัวเลข/เวลาเท่านั้น** ห้ามใช้กับคำไทย |
| `pixel` | Silkscreen | คำอังกฤษสั้น เช่น LV XP HP |

- ขนาดตัวหนังสือเนื้อหาไม่ต่ำกว่า 14 · ตัวเล็กสุด (ป้ายแท็บ ข้อความประกอบ) 12

## การใช้งาน
- ปุ่ม/จุดกดสูงอย่างน้อย 44px (`minTouch`) · คอนทราสต์ ≥ 4.5:1 · ใช้ได้ตั้งแต่จอ 360px
- แท็บล่าง 5 แท็บ: วันนี้ · วิชา · งาน · เกม · ตั้งค่า
- โหลด = skeleton ไม่ใช้วงกลมหมุน
- แอนิเมชันใช้ `transform` / `opacity` เท่านั้น · เคารพ reduce motion
- การกดที่ย้อนได้ (ติ๊กส่งงาน) = แถบ "ยกเลิก" 3 วินาที
