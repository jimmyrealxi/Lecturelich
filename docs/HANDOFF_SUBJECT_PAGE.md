## ข้อสรุปล่าสุดกับเจ้าของ (หน้าวิชา) — ยังไม่ได้แก้ mockup
เจ้าของบอก: หน้าวิชา "นาน ๆ เข้าที เข้าแบบตั้งใจมาเช็ก" · ใช้ยาก ข้อความเยอะ จาง อ่านแล้วงง
→ ลำดับเดิมไม่ผิด ที่ผิดคือข้อความเยอะ + ฟอร์มคะแนนเปิดค้างทุกส่วน · ตัด "คาบหน้า" "ปุ่มเพิ่มงาน" "ต้องทวนกี่หัวข้อ" ออกแล้ว (เจ้าของถามว่าควรมีไหม → ไม่จำเป็น)
แบบที่เสนอล่าสุด (รอเจ้าของตอบ "โอเค"):
1. สรุป 2 ช่อง (จอเขียวจิ๋ว): `มาเรียน 100% · ขาดได้อีก 2` · `D-111 สอบปลายภาค`
2. คะแนน: `เก็บแล้ว 18/25 (72%)` (แทน "ถ้าจบตอนนี้ได้ B+" ที่หลอกตาต้นเทอม) · เป้า [B ▾] ช่องเลือกเดียว (แทนปุ่ม 7 ปุ่ม) · "ปลายภาคต้องได้อย่างน้อย…" · แต่ละส่วนคะแนนเป็นแถวเดียว **แตะค่อยกางฟอร์ม**
3. โน้ต 2 สัปดาห์ (ไทม์ไลน์ย่อที่ทำแล้ว)
4. งานของวิชา (ไม่มีงาน = บรรทัดเดียว ไม่มีภาพ EmptyScene ใหญ่)
5. ตั้งค่าวิชา ยุบไว้ท้ายหน้า: ชื่อ ตาราง วันสอบ คาบชดเชย เกณฑ์ตัดเกรด · ปุ่ม "แก้ไข" มุมบนพามากางที่นี่ (ตั้งค่าที่เดียว)
- ข้อความ: ตัวหลัก 16px สีหมึก · สีจางเฉพาะวันที่ ≥14px · ตารางข้อความเก่า→ใหม่อยู่ใน mockup (`.side table`) เช่น "งานที่ได้ 0 ให้กรอก 0 ด้วย…" → "ได้ 0 ก็ใส่ 0 (ไม่ใส่ = ไม่นับ)" โผล่ตอนกางฟอร์มเท่านั้น · ตัด "ตั้งแล้วจะเกิดบอส / เว้นว่าง = ยังไม่มีบอส"
- วิธีคิดคะแนน/เกรดไม่เปลี่ยน · ไฟล์ที่เกี่ยว: `app/subject/[id].tsx` `components/GradesPanel.tsx` `ExamDatesCard.tsx` `MakeupClasses.tsx` `app/subject/edit.tsx`
