## ต้องทำ (ทีละขั้น เทสที่จอ 390 + 360 ในเครื่องก่อน push ทุกครั้ง)
1. **token**: `lib/theme.ts` เปลี่ยนสีตาม `:root` ใน mockup (ink/deck/rule/paper/muted/faint/go/warn + cave/seam/bone/ash/gold/blood) แล้วอัปเดต `docs/DESIGN.md` ให้ตรง (ตอนนี้ยังเป็นธีมฟ้า-ครีม)
2. **ฟอนต์**: ติดตั้ง `@expo-google-fonts/chakra-petch` (หัวข้อ/ปุ่ม/แท็บ ภาษาไทย) + `@expo-google-fonts/vt323` (ตัวเลข/เวลาเท่านั้น ห้ามใช้กับคำไทย) · คง IBM Plex Sans Thai (เนื้อหา) + Silkscreen (LV/XP) · เลิกใช้ Kanit
3. **แถบแท็บ**: `app/(tabs)/_layout.tsx` → แผงทึบติดขอบล่าง ขีดสีเหนือแท็บที่เลือก ไอคอน SVG เส้นเหลี่ยมตาม mockup (ใช้ `react-native-svg` ถ้ามี ไม่งั้นถามก่อนติดตั้ง) · ป้ายเลขค้างบนแท็บงาน · **คงค่า** tabBarStyle height `56 + max(insets.bottom,10)` + label lineHeight 18 / flexShrink 0 (แก้บั๊ก iPhone แล้ว ห้ามถอย)
4. **หน้าวันนี้** `app/(tabs)/today.tsx`: ตัวเด่นตัวเดียว (กำลังเรียน / คาบถัดไป+นับถอยหลัง / ไม่มีคาบ→งานใกล้สุด) · เช็กชื่อ = สวิตช์ 2 ปุ่ม (มาเรียน/ขาด) + ลิงก์ "วันนี้อาจารย์งดสอน" (= no_class เดิม) · "ค้างอยู่" เป็นบรรทัด log (ไม่ใช่การ์ด) · ช่องติ๊กพื้นที่กด 44px + toast "ยกเลิก" 3 วิ · บันทึก XP ยุบเป็นบรรทัดเดียวลิงก์ไปหน้าเกม · วันที่แบบไทย "เสาร์ 7 พ.ย." / "อ. 11 พ.ย."
5. **หน้าเกม** `app/(tabs)/game.tsx`: ฉากบอส + สไปรต์ (ตอนนี้ CSS box-shadow ใน mockup → ในแอปทำเป็น View กริด หรือ PNG pixelated) · รายชื่อหัวข้อใต้ passive tree (สี rarity + วันทวนรอบถัดไป) · ของที่เก็บได้วันนี้
6. หน้าอื่น (วิชา/งาน/ตั้งค่า/login/note/room) เปลี่ยนตาม token — ทำ mockup เพิ่มก่อนถ้าโครงเปลี่ยน

- iPhone PWA: **ห้ามใส่ `viewport-fit=cover`** และ status-bar-style ต้อง `default` (ไม่งั้นหัวจาง/ช่องว่างล่าง) · แก้ +html แล้วต้องลบไอคอนแล้วเพิ่มใหม่ถึงเห็นผล
