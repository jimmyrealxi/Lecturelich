Pap-Boy v1 — ตัวละคร + ตู้แต่งตัว

เด็กหมวกนิรภัย หน้าเป็นจอ (ตา/ปากเรืองแสงบนจอ เปลี่ยนอารมณ์ได้) ใส่ฮู้ด ถุงมือขาว · ตัวอ้วนสั้นสัดส่วน 2 หัว อ่านง่ายแม้ภาพเล็ก · คลังของ: แตะของ = ลองใส่บนตัวละครทันที กด "ใส่" ถ้าชอบ · ของที่ยังไม่ได้เป็นเงาดำ "???" ลองดูได้แต่ใส่ไม่ได้ · ของทุกชิ้นวาดซ้อนเป็นชั้น: ออร่าหลัง → ปีก → ออร่าพื้น → ตัว → ของสวม → อนุภาคหน้า · ปุ่มต้น/กลาง/ปลายเทอม = ดูตัวอย่างชุด · สีกรอบช่อง = ความหายาก

Pap-Boy
  • ท่าประจำตัว (แบห้านิ้ว) กับท่าตอบสนองอื่น ๆ ใช้ตัวเดียวกันนี้ ทำต่อหลังอนุมัติรูปร่าง
